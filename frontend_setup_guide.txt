=========================================
KisanSetu AI - Frontend Setup Guide
=========================================

This guide will help you set up and run the KisanSetu frontend on your local system.

-----------------------------------------
1. Prerequisites (What to Install)
-----------------------------------------
Before you begin, ensure you have the following installed on your system:

a) Node.js & npm (Required to run the React application)
   - Download from: https://nodejs.org/ (Download the "LTS" version)
   - To verify installation, open a terminal (Command Prompt/PowerShell/Terminal) and type:
     node -v
     npm -v
     (Both should output a version number without errors)

b) Git (Required to clone the repository)
   - Download from: https://git-scm.com/downloads

c) VS Code (Recommended Code Editor)
   - Download from: https://code.visualstudio.com/

-----------------------------------------
2. Cloning the Repository
-----------------------------------------
1. Open your terminal or command prompt.
2. Navigate to the folder where you want to download the project.
3. Run the following command:
   git clone https://github.com/Paramfpv/SIH-KisanSetu.git
4. Move into the newly created folder:
   cd SIH-KisanSetu

-----------------------------------------
3. Installing Dependencies & Running
-----------------------------------------
Since this is a Vite + React project, all the code is inside the "frontend" folder.

1. Move into the frontend directory:
   cd frontend

2. Install all the required packages:
   npm install

3. Start the local development server:
   npm run dev

-----------------------------------------
4. Viewing the Application
-----------------------------------------
After running `npm run dev`, your terminal will show a local URL, usually:
http://localhost:5173/

1. Open your web browser (Chrome, Edge, Firefox, etc.).
2. Go to http://localhost:5173/
3. You should see the KisanSetu Sign In page!

Note: If you make changes to the code and save, the browser will automatically refresh with your new changes.

-----------------------------------------
Troubleshooting
-----------------------------------------
- If you get a "Command not found: npm" error, make sure Node.js is installed correctly and you restart your terminal.
- If you see a blank page, check your terminal for any build errors.
- Always make sure you are inside the "frontend" folder before running `npm install` or `npm run dev`.
